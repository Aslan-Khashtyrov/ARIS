# Project One — архитектура MVP

Project One — Android-first гибридное приложение с нативной оболочкой Capacitor и React-интерфейсом.

## Неподвижные правила

- Родной и исходный язык интерфейса — русский.
- Другие языки в будущем переводятся с `russianSource`; при отсутствии строки используется русский оригинал.
- ARIS остаётся paper/simulation-only; реальные сделки из приложения не включаются.
- Секреты, API-ключи, токены, пароли и платёжные данные не хранятся в репозитории.
- Встроенные сервисы открываются только по HTTPS и только из allowlist.
- Локальный bridge допускает только loopback: `localhost`, `127.0.0.1`, `::1`.
- Приложение не получает произвольный shell-доступ само по себе.

## Модули

- `App.jsx` — навигация и состояние приложения.
- `Screens.jsx` — экраны Чат, Агенты, Терминал, Сервисы, ARIS, Расходы, Настройки.
- `i18n.js` — канонический русский источник пользовательских строк.
- `agents.js` / `router.js` — реестр агентов и локальный выбор маршрута.
- `services.js` — разрешённые встроенные веб-сервисы.
- `localBridge.js` — безопасная валидация и health-check локального моста.
- `storage.js` — локальное сохранение настроек и истории.
- `scripts/security-selfcheck.mjs` — регрессионные проверки базовых границ безопасности.
